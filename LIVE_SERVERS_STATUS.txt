🆘 IF SOMETHING BREAKS
═══════════════════════════════════════════════════════════════════════════════

  Backend won't respond:
  1. Kill: kill <PID> or pkill -f "main.py"
  2. Check logs: tail /tmp/backend.log
  3. Restart: python backend/main.py

  Frontend issues:
  1. Kill: kill <PID> or pkill -f "npm"
  2. Check logs: tail /tmp/frontend.log
  3. Restart: cd frontend && npm run dev

  Port conflicts:
  1. Backend: lsof -i :8000
  2. Frontend: lsof -i :5173
  3. Kill: kill -9 <PID>
